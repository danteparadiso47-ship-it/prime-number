소수 판별기

정수를 입력해 소수 여부를 확인하고, 아래에서 각 함수가 연결되는 방식을 살펴보세요.

1. 실행해 보기

정수를 입력해 주세요.
현재 상태: 입력 대기 중

2. 함수 연결 구조

user_input()입력창의 값을 정수 x로 받아 반환합니다.
→
main()입력값을 num에 저장하고 prime(num)을 호출합니다.
→
prime(x)rest에 나머지를 저장해 소수 여부를 출력합니다.

3. 원본 소수 판별 코드

def user_input():
    x = int(input("Please enter an integer: "))
    print(f"your number is: {x}")
    return x

def prime(x):
    if x < 2:
        print(f"{x} is not a prime number.")
    else:
        rest = [x % i for i in range(2, x)]
        if 0 in rest:
            print(f"{x} is not a prime number.")
        else:
            print(f"{x} is a prime number.")

def main():
    num = user_input()
    prime(num)

main()

rest에는 2부터 x-1까지 나눈 나머지가 저장됩니다. 그 안에 0이 있으면 약수가 있으므로 소수가 아닙니다.
